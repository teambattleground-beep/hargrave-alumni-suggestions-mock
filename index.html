How a suggestion moves

One note. One inbox.

Alumni write. The note is addressed to alumnifeedback@hargrave.edu. An administrator opens a locked inbox. Nothing here is a ticket.

  1. 01

    You write it

    Your name, your class year, and the suggestion. An email is optional, only if you want a reply.

  2. 02

    It is addressed

    The live note goes to alumnifeedback@hargrave.edu. This mockup does not send mail. It keeps the note for the administrator inbox.

  3. 03

    An administrator reads it

    The inbox is password protected. From there, the notes go on to the Alumni Board group.
